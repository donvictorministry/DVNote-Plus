About DV-NOTE plus

DV-NOTE plus is an Android-exclusive, edge-to-edge confidential note vault and bidirectional cryptographic client-side API engine.

It utilizes the browser's native Web Crypto API (AES-GCM 256-bit with PBKDF2 SHA-256 derivation) to guarantee client-side zero-knowledge security. No unencrypted text is ever stored, transmitted, or logged. All operations run 100% offline via Service Worker.

How to Use

  1. Initialize Vault: Enter your secret Master Passphrase into the top lock bar and tap "Unlock".
  2. Store Confidential Notes: Add a Title and Content, then tap "Encrypt & Store Note". Data is encrypted in memory via AES-256 prior to persistence.
  3. Two-Way API Usage: Open the right menu (⋮) to explore the API Console. Other apps can transmit data to this app for headless client encryption without server infrastructure.
  4. Data Portability: Export or import raw encrypted JSON backups at any time.
